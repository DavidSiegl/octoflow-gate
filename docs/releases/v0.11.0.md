# The gate lists a block a change copies

A new check, `duplicated-blocks`, lists for the Reviewer to weigh each block of code a change adds that the tree
already holds elsewhere, or that the change adds twice, names and literals aside: a copy is logic that has to be fixed
twice, and a change is where it enters. The finding lies at the copy's first line and names the other place as
`path:line`. [docs/quality-gate.md](https://github.com/DavidSiegl/octoflow-gate/blob/main/docs/quality-gate.md) says
how each language's code is read.

- **What counts**: a run of at least 50 tokens, all on lines the change added, equal to a run in another file, in the
  same file where the two do not overlap, or a second time in the change, which is then one finding at the later copy.
  Python, Rust and Go are read; generated Go files are not.
- **Names and literals aside**: a name stands for what kind of name it is and a literal for what kind of literal, so a
  copy whose names and values were changed is still one. Comments, `use` and `import` statements, Go's `package`
  clause and Rust's `#[cfg(test)]` code are left out.
- **Settings**: `[duplicated-blocks]` in `gate.toml` sets `exempt`, the files neither judged nor matched, by default
  the tests, fixtures and `testdata`, and `min-tokens`, the shortest run reported.
- **Never fails**: the finding is one to weigh, and no comment suppresses it.

A change that passed under 0.10.0 still passes. Over 100 commits of this repository, 30 findings, 24 of them real
copies such as the Go front end started from the Rust one; over 100 of octoflow-ai, 2, both siblings of one shape.
