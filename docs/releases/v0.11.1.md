# Two gates with Go and one TMPDIR no longer fail each other

golangci-lint lets one instance run at a time per `TMPDIR`, where it keeps its lock, and by default a second one exits
with "parallel golangci-lint is running". The gate passed that on as a failed condition, so two gate runs over Go
modules at once with one `TMPDIR`, as on a CI agent whose executors share one, could fail a change for nothing in it.
The gate now runs golangci-lint with `--allow-serial-runners`: a second run waits for the first, and the wait counts
in its ten-minute timeout.

A change that passed under 0.11.0 still passes; one that failed only on that condition passes.
