# passes-at-base runs a Rust test in the targets Cargo builds it in, and cargo-mutants mutates whole edited functions

passes-at-base finds the Cargo targets of a changed Rust test from `cargo metadata` and the module tree the files'
`mod name;` items make, `#[path]` included, where 0.12.1 read them off Cargo's default layout. A test in a `[[test]]`
with a `path`, in a bench or an example, in a module of `src/main.rs` beside a `src/lib.rs`, or in a module a
`#[path]` places, is now run in its target and can be a `passes-at-base` finding; 0.12.1 named such a test's target
wrong, so nextest ran nothing and it gave no finding, or reported it `not-run`. A test in a module two targets share,
as a `tests/common/mod.rs` two integration tests declare, is run in each and found only when it passes in both, where
0.12.1 reported it `not-run`. A test no target builds stays a `not-run` finding, and so is one whose package `cargo
metadata` cannot read.

surviving-mutants mutates the Rust functions a change edits, as it does Python's and Go's: a `fn` the change adds a
line to or removes lines from, outside test code, has all its mutants tried, given to cargo-mutants by `--re` in place
of 0.12.1's `--in-diff`, which mutated only what added lines held. A change that only removes a guard clause from a
function now has that function mutation-tested, and a change to one line of a function can now find survivors
elsewhere in it. A `.rs` file the gate cannot parse is a `not-run` finding, its functions not mutated. A file whose
path repeats its workspace's directory, as `core/lib/core/src/x.rs` in workspace `core`, is mutated, where 0.12.1
took the directory out of the path wherever it recurred and so named a file that does not exist. A file whose
workspace's directory is not above it, as a `package.workspace` can name, is a `not-mutated` finding.

passes-at-base no longer runs a Rust test at the base because the change deletes the test just below it: 0.12.1
counted lines removed right after a test's closing line as an edit to that test, so the test above a deleted one ran
at the base, passed, and was reported as passing without the change.

All findings these change are warnings, so verdicts and exit statuses are as under 0.12.1.
