# passes-at-base builds a Rust workspace that commits no lock file

passes-at-base runs `cargo nextest` with `--locked` only where the base tracks the workspace's `Cargo.lock`, as clippy
already did. 0.12.2 passed it always, so in a workspace that commits no lock file cargo refused to build at the base
and every changed Rust test was a `not-run` finding; such tests are now judged.

All findings these change are warnings, so verdicts and exit statuses are as under 0.12.2.
