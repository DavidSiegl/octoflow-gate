# test-integrity sees a Go test's expected values in its table of cases and in the file's constants

A Go test's table of cases, a composite literal that a `for … range` in the test ranges over, directly or by the name a
`:=` or a `var` binds it to, as `for _, c := range []struct{ in, want int }{{in: 2, want: 4}}`, now holds expected
values: each of its elements written in braces of its own is a case and an assertion of the test, so `{in: 2, want: 4}`
becoming `{in: 2, want: 5}` in a change that also edits Go code is an `expected-value-changed` finding at the case, and
a case removed is `fewer-assertions`. A top-level `const` a test's assertions name, as `const want = 3`, edited beside
the code is one too, as Python's and Rust's constants are. 0.12.3 saw neither, and counted a table's cases as no
assertions.

## An assertion added beside others of its shape leaves them unchanged

In a run of consecutive assertions of one shape that grew or shrank, expected-value-changed now matches the ones that
stayed whole before it pairs the rest, in every language. 0.12.3 paired them by shape alone, so an assertion added or
removed beside others of its shape, as a case appended to a table, shifted them onto their neighbours: each was
reported as an expected value edited into the next one's. A run that kept its length is paired in order, as before.

## SIGTERM stops the gate and what it started

A gate sent SIGTERM, as `timeout` stops a command, now kills the processes it started, each tool's whole session,
and exits 130 having written no report, as it does on Ctrl-C. 0.12.3 died on SIGTERM at once and left its tools
running. A gate started with SIGTERM ignored leaves it ignored, as it does SIGINT.

## surviving-mutants leaves the files mutmut does not mutate as they are

In its copy of the tree, surviving-mutants now marks for mutmut to skip only the functions of the files mutmut
mutates, those under `[tool.mutmut]` source_paths that its only_mutate and do_not_mutate keep. 0.12.3 read and
marked every `*.py` in the copy, so a test file there carried the marks, and one it could not read failed the check
as `not-run`.

Verdicts and exit statuses are otherwise as under 0.12.3.
