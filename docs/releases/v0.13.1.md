# test-integrity reads a Go test file's legacy `// +build` lines

In a Go test file with no `//go:build` line, a `// +build` line added above the package clause is now a `skip` or a
`platform-only` finding, as a `//go:build` line is: go 1.17 and later still obey such lines there. Its space-separated
options are or'd and each option's comma-separated tags and'd, and a file's `// +build` lines are and'd, each line
judged by the constraint they make together. 0.13.0 read `//go:build` alone, so `// +build ignore` turned a file's
tests off unseen.

Verdicts and exit statuses are otherwise as under 0.13.0.
