# The quality file's parts carry octoflow's names

Nothing a run of the gate writes changes: the quality file and `quality.json` are byte for byte what 0.15.0 wrote.

The constants and functions that write the quality file's parts now have the names octoflow's engine gives its copy
of them, `QUALITY_OK`, `QUALITY_ERROR`, `QUALITY_FINDINGS_LIMIT`, `QUALITY_FAILED_CONDITIONS`, `QUALITY_FAILING_TESTS`
and `QUALITY_TO_WEIGH_NOTE`, so a search for one part finds both programs' copies; docs/quality-gate.md, "The report
as a contract", names them beside the parts. `text::clip`, which cuts a tool's message to 160 characters, is
`text::shortened`, after the engine's helper that does the same.
