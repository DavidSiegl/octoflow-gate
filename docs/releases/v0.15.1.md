# The quality file's parts carry octoflow's names

Nothing a run of the gate writes changes: the quality file and `quality.json` are byte for byte what 0.15.0 wrote.

The constants that hold the quality file's parts now have the names octoflow's engine gives its copy of them,
`QUALITY_FINDINGS_LIMIT`, `QUALITY_FAILED_CONDITIONS`, `QUALITY_FAILING_TESTS` and `QUALITY_TO_WEIGH_NOTE`, and
`text::clip` is `text::shortened`, so a search for one part finds both programs' copies. docs/quality-gate.md, "The
report as a contract", names each part's constant.
