# A failing test's line says why it failed

The quality file's line for a failing test kept only the first line of what failed. For a Rust test that line says
only where the test panicked, and cargo-nextest's JUnit report gave the gate nothing more: its `message` is the panic's
first line alone. The gate now reads a failure's text when it opens with the message, so the detail, in full in
`quality.json`, is the panic and what the test printed on standard error after it. The quality file's line adds the
panic's message, from the line after, and the first line naming `OCTOFLOW_TEST_SEED`, the run seed with which
octoflow's generated-input tests generate a failing case again. Each failing test is still one line of the quality file.
