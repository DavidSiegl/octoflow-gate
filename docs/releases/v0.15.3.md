# The gate as 0.15.2, published after immutable releases were turned on

The gate is unchanged from 0.15.2. This release is the first published since the repository's immutable-releases
setting was turned on, which keeps a release's assets and tag from changing once it is out, so that a pin naming it,
with its tarball's sha256, keeps meaning the same release. Its build is also the first to check, before releasing,
that octoflow's main drives the release tarball.
