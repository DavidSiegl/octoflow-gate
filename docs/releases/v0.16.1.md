# The checks read a change's sources once

The gate judges as 0.16.0 did. Its checks that run a change's code, passes-at-base, surviving-mutants and
flaky-tests, now take each file of the change from what the parser checks already read, instead of reading it again
from the working tree and from git. surviving-mutants no longer starts a `git cat-file` for each base Go file whose
functions it compares.

One case changes: a Go file whose base is a symlink or a submodule rather than a regular file has its functions
counted as edited, where 0.16.0 read the base through git all the same. It is rarely reached, and errs towards
mutating a function.
