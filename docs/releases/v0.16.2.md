# One copy of the tree per check

flaky-tests, surviving-mutants and passes-at-base each make one copy of the tree for all the languages they run,
where they made one per language:

- flaky-tests reruns a change's Python and Go tests in one copy of the working tree;
- surviving-mutants runs mutmut, cargo-mutants and gremlins in turn in one copy of the working tree;
- passes-at-base runs the Python, Rust and Go tests at the base in one copy of the base, which takes from the working
  tree the files that go with the tests of any of the three. A Python test that reads a Go package's `testdata/` now
  sees the working tree's there.

The findings for a copy that cannot be made or removed now have one wording for every check, ending in what was not
judged: "could not copy the base: …; the changed tests were not run at the base.", "could not remove the directory of
the copy of the working tree, `…`: …". A submodule the base's copy leaves empty is one finding however many languages
run there, saying "a changed test that needs it" for every language.
