# Each runner check owns its language halves

flaky-tests, surviving-mutants and passes-at-base each hold their Python, Rust and Go halves in one module of their
own, which share one budget and one wording for what they could not judge:

- A changed Python file that does not parse is a finding at the line the parse failed at, as a Rust or Go one is,
  where it was a finding on the whole file.
- passes-at-base's Python runs count `--base-run-budget` from the start of the check, as Rust's and Go's do, where they
  counted it from when the copy of the base was ready. surviving-mutants' mutmut counts its share of
  `--mutation-budget` from the start of the check too, so that what readies its run, such as reading
  `--test-contexts`, takes from its share rather than from the languages after it.
- surviving-mutants' `not-run` findings on Python end "the change's Python was not mutation-tested.", as Rust's and
  Go's name their language, where they said "the change's functions".
- A `mutants/` that gremlins cannot remove from the copy names the path it could not remove.
