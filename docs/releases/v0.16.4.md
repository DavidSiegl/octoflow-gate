# The gate's library lists its interface

The `gate` crate's modules are private, and its root re-exports what the `gate` binary and the crate's tests use.
Nothing a release ships changes: the binary's flags, exit statuses, quality file and quality.json are as in 0.16.3.

docs/adr/0001-parser-checks-test-through-a-real-tree.md records why the parser checks' tests run on a real git
repository rather than an in-memory stand-in for the change's sources.
