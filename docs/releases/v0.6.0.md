# The Rust gate rides along

`gate.py` judges as in 0.5.0; nothing changes for a project that only raises its pin.

- **The tarball also holds `gate-linux-x86_64`**, the gate's port to Rust as one binary, built for Linux x86_64. It
  takes `gate.py`'s arguments and writes the same two reports. It does not judge yet.
- **`shadow-run.sh`**, beside it, runs that binary on a change `gate.py` has judged and writes `quality-rust.md`,
  `quality-rust.json` and `quality-diff.txt`, the difference between the two gates' reports, for a CI to archive. The
  README's "The Rust gate's shadow run" shows how;
  [docs/port-differences.md](https://github.com/DavidSiegl/octoflow-gate/blob/main/docs/port-differences.md) lists
  the differences that are meant.
