# The gate is one binary

`gate`, the gate's port to Rust, judges from this release on; `gate.py` and its gate-rust helper are gone. A project
that raises its pin changes how it starts the gate, and should read
[docs/port-differences.md](https://github.com/DavidSiegl/octoflow-gate/blob/main/docs/port-differences.md), which
lists where `gate` judges or words a change differently from `gate.py`.

- **The tarball** holds `gate`, built for Linux x86_64, the schema in `schema/`, golden quality files in both
  formats in `golden/`, and the README. No `gate.py`, no `gate-rust`, no `shadow-run.sh`; 0.6.0's
  `gate-linux-x86_64` is this `gate`.
- **Run `gate --base REV`** where `python gate.py --base REV --rust-syntax PATH` ran. `--rust-syntax` is gone and
  refused: the gate reads Rust and Python itself, and needs no Python to start. The exit statuses, the quality file's
  contract and quality.json (`schema_version` 1) are unchanged.
- **`--python PATH`**, or the `python` key of `gate.toml`, names the judged project's Python, in which its pytest,
  pytest-randomly and mutmut are installed; without either it is `python3` from `PATH`. `gate.py` used the Python
  that ran it, so a project that started it with `uv run python gate.py` now starts `uv run gate --python python`,
  or names its environment's Python.
- **`--config` names a gate.toml alone**, and is refused when it names a `pyproject.toml`. The rules of ruff, mypy,
  pymarkdown and mutmut are those of the `pyproject.toml` beside that gate.toml: a CI that judges by `main`'s rules
  puts `main`'s `pyproject.toml` beside `main`'s `gate.toml` and passes the one `--config`. Where no `pyproject.toml`
  is there, the linters run on their defaults and mutmut does not run: no project needs a `pyproject.toml`.
- **A change can no longer loosen pymarkdown.** Under every release up to 0.6.0, pymarkdown added the judged tree's
  own `[tool.pymarkdown]` or `.pymarkdown` to the rules `--config` named, so a change could turn a rule off for
  itself. It now runs in an empty directory of the gate's own.
- **A coverage report may be LCOV** as well as Cobertura.

To go back, lower the pin to 0.6.0 or 0.5.0, whose `gate.py` judges; both stay published.
